# Belle Ringer Counter

Static mobile-friendly IronPAX Week 3 counter.

## GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html` to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will display the public URL after deployment.

Progress and finalized scores are stored locally in each user's browser.
The Submit Score button opens https://ironpax.f3greenwood.org/submit
